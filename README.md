# ControlGas

Sistema web para el control diario de ventas e inventario de cilindros de gas Duragas y King Gas.

Permite registrar ventas, controlar cilindros llenos, vacíos y reservados, gestionar pagos y tanques pendientes, realizar cierres diarios y mantener un historial de operaciones.

Desarrollado con HTML, CSS y JavaScript, utilizando LocalStorage para almacenar la información en el navegador.
